GuideDeck 0.4：Steam Guide 行為修正

首頁改為 Steam Guide：原生兩個 Guide 選項 → 選取帳號或安裝設定 →
讀回／預覽／局部備份套用 → 重啟 Steam 做背景／前景／遊戲測試。
舊 SDL mapping 頁改為進階工具，不能作為已阻擋大螢幕的證明。
自動流程只修改已存在且格式明確的布林值；缺少值一律是未知。
Steam Guide 開關與 mapping 使用不同備份格式，提供各自的還原入口。
Game Bar 顯示目前選取檔案的開關摘要與時間，不顯示攔截成功狀態。

GuideDeck 0.3 介面設計

主要流程：選擇設定與控制器 → 預覽修改 → 備份並套用 → 遊戲驗收。
左側導覽集中 Steam 設定、對應工作台、遊戲驗收、觀察紀錄與 Game Bar。
設定頁底部固定套用／還原操作，避免長內容讓主要動作藏在捲動區下方。
窄視窗與高 DPI 使用可捲動內容；視窗啟動時限制在可用工作區內。

視覺：中性色背景、表面卡片、明確標題與輔助文字；綠色用於主要
動作與選中導覽，琥珀色只表示實驗性範圍，不能用綠勾暗示攔截成功。
原始與修改後對應並排，原始字串保留等寬字體；技術細節留在工作台。

外觀：預設跟隨 Windows 應用程式主題，可手動選淺色或深色。
主題偏好存 appearance.json，與 Steam 設定分開；同套件的 widget 與
桌面管理器共用偏好。Game Bar 的自動模式尊重宿主 RequestedTheme。
Windows 高對比優先於手動選擇；widget 使用 HighContrast theme resources。
桌面標題列也會切換，但舊 Windows 對 DWM 深色標題列的支援依版本而定。

桌面文字、次要文字、主要按鈕、選中項與提示文字檢查 4.5:1 對比；
輸入框邊界檢查 3:1。鍵盤焦點使用可見外框，Game Bar 保留原生手把
導覽與至少 44 DIP 的按鈕。未完成遊戲內手把／Narrator 的實機驗收。

CI 以真正的 WPF 視覺樹產生淺色／深色 PNG，並確認產生預覽不改變
偏好檔。系統主題測試只在隔離的 GitHub Actions runner 上執行，會還原
測試用登錄與偏好值；一般程式不修改 Windows 主題設定。
